## 它解决什么问题

工厂每年要做碳盘查，但大部分 EHS 还在用 Excel 手工算。这个工具把「用量 × 排放因子」的计算固化下来，几秒钟出结果。

## 排放因子

| 能源 | 因子 | 单位 | 适用年份 | 来源 |
|---|---|---|---|---|
| 电力 | 0.5306 | kgCO2 / kWh | 2023 | 生态环境部、国家统计局《关于发布2023年电力二氧化碳排放因子的公告》（公告 2025 年第 47 号） |
| 天然气 | 2.16 | kgCO2 / m³ | 2011 | 《省级温室气体清单编制指南（试行）》缺省值 |
| 柴油 | 2.68 | kgCO2 / L | 2011 | 《省级温室气体清单编制指南（试行）》缺省值 |
| 汽油 | 2.36 | kgCO2 / L | 2011 | 《省级温室气体清单编制指南（试行）》缺省值 |

### 分区域电力因子

电力因子随区域不同——西南、南方水电多，因子低；华北、西北火电多，因子高。

| 华北 | 东北 | 华东 | 华中 | 西北 | 南方 | 西南 |
|---|---|---|---|---|---|---|
| 0.6361 | 0.5122 | 0.5500 | 0.5271 | 0.5543 | 0.4042 | 0.2472 |

**同样一万度电：华北排放 6.4 t，西南 2.5 t，相差 61%。** 所以工具里先选工厂所在区域，再算排放。

> 以上为常用缺省因子，**正式碳核算请以最新官方发布文件为准**。>

## Scope 划分

- **Scope 1**：企业自有或控制的排放源，直接燃烧燃料
- **Scope 2**：外购电力、热力产生的间接排放
- **Scope 3**：价值链上下游的其他间接排放（本工具暂未覆盖）

## 功能

- 输入四种能源的年度用量，自动计算分项排放
- 输出总排放、Scope 1、Scope 2 三个指标
- 各能源排放量对比柱状图
- 换算「相当于多少棵树一年的吸收量」

## 运行方式

    pip install -r requirements.txt
    python -m streamlit run carbon.py

## 一个设计考虑

能源的种类、因子、所属 Scope 都写在一张配置表 `ENERGY` 里，循环遍历生成输入框和计算逻辑。新增一种能源（比如外购蒸汽）只需在配置表加一行，不用改动任何计算代码。
