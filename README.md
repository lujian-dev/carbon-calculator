# \# 工厂碳排放计算器

# 

# 按 GHG Protocol 口径，计算工厂的 Scope 1（直接排放）与 Scope 2（外购电力间接排放）。

# 

# \## 它解决什么问题

# 

# 工厂每年要做碳盘查，但大部分 EHS 还在用 Excel 手工算。这个工具把「用量 × 排放因子」的计算固化下来，几秒钟出结果。

# 

# \## 排放因子

# 

# | 能源 | 因子 | 单位 |

# |---|---|---|

# | 电力 | 0.5568 | kgCO2 / kWh |

# | 天然气 | 2.16 | kgCO2 / m³ |

# | 柴油 | 2.68 | kgCO2 / L |

# | 汽油 | 2.36 | kgCO2 / L |

# 

# 电力因子取自生态环境部公布的全国电力平均排放因子，使用前请核实最新版本。

# 

# \## Scope 划分

# 

# \- \*\*Scope 1\*\*：企业自有或控制的排放源，直接燃烧燃料

# \- \*\*Scope 2\*\*：外购电力、热力产生的间接排放

# \- \*\*Scope 3\*\*：价值链上下游的其他间接排放（本工具暂未覆盖）

# 

# \## 功能

# 

# \- 输入四种能源的年度用量，自动计算分项排放

# \- 输出总排放、Scope 1、Scope 2 三个指标

# \- 各能源排放量对比柱状图

# \- 换算「相当于多少棵树一年的吸收量」

# 

# \## 运行方式

# 

# &#x20;   pip install -r requirements.txt

# &#x20;   python -m streamlit run carbon.py

# 

# \## 一个设计考虑

# 

# 能源的种类、因子、所属 Scope 都写在一张配置表 `ENERGY` 里，循环遍历生成输入框和计算逻辑。新增一种能源（比如外购蒸汽）只需在配置表加一行，不用改动任何计算代码。
